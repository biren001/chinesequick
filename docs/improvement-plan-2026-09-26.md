## 0. 结论一句话

那份分析的方向是对的（窄定位、内容规模、留存闭环），但它看不到代码，所以 **6 条建议其实是已经做完的事**，另有 **2 条按它写的做会踩坑**。

真正该改的不是「把 50 条变 500 条」，而是：

> **先补 `everyday` / `emergency` 这两个搜索需求最集中的簇，再把「收藏 + 错题复习」这两个最便宜、最直接的留存杠杆装上。**

### 2.2 它判断正确的（7 条）

内容规模是瓶颈（#2）、窄定位（#3）、**收藏（#6）**、复习闭环（#7）、7 天课程（#8）、SEO 页要有实质内容（#10）、先别收费（#16）、不做 AI 老师（#13）。

### 2.3 要打折扣或改写的（3 条）

**#4「50 → 500 phrases」——数字是错的处方。**
按「每类再塞 40 条」去做，会产出 500 个搜不到的冷词 + 一大批薄页面。正确做法是**按查询需求补**，不是按数量凑。见 §3。

**#14「What do you want to say?」自由输入——唯一会真踩坑的一条。**
纯静态 + 零成本做不了语义理解。硬做只能是「关键词匹配假装 AI」：用户第一次输入 “I want to order food” 没命中，落差比没有这个功能更伤，而且它无法随内容扩张自然变好。
→ 改成**意图索引**：把 30–50 个常见说法（“I want to order food” / “I'm lost” / “no spicy” / “where's the toilet”）显式映射到短语，输入走本地匹配，UI 上诚实写 `Try: I'm lost · no spicy`。零成本、零后端、体验不塌。

**#17 Travel Pack 收费——现在做是错的。**
等于把最便宜的变现方式（免费 + 广告/联盟）换成转化率极低的付费墙，而这个受众（来中国短途旅行者）价格极敏感。
真的要做，形态应该是「把免费内容变得更方便」（离线包 / PDF / 音频打包下载），而不是「锁住短语」。

### 2.4 明确不做

AI 对话老师（#13）、Dating 分类（无内容支撑 = 死链感）、会员制。

## 3. 真正的瓶颈：不是 50 条，是**缺哪些**

实测 50 条的分布与缺口：

| 分类 | 现状 | 缺口 |
|---|---|---|
| Restaurant (10) | 点菜、买单、不要辣 | 缺「有什么推荐 / 我吃素 / 我对花生过敏 / 加饭加水」这一簇 |
| Travel (10) | 机场、火车站、厕所、护照 | 缺**整簇 Emergency** |
| Hotel (10) | 入住退房、空调坏了、寄存 | 健康 |
| Shopping (10) | 便宜点、试穿、刷卡、退 | 缺「退税 / 有更大的吗 / 收现金吗」 |
| **Everyday (10)** | 你好、谢谢、对不起、再见… | **最值钱的一类，目前最薄的一类** |

**全球搜索量最大的语言类查询几乎全落在 everyday，而我们现在一个都没有：**

```
how to say yes        how to say no          how to say excuse me
how to say I love you how to say good morning how to say good night
how to say I don't know              how to say please
how to say my Chinese is not good    how to say cheers
```

→ 内容扩张的第一批应 **100% 落在 everyday + 新增 emergency**，不要平均撒。

## 4. 我的优先级

### P0（这一轮就该做）

**1. 按簇补内容：50 → 约 100**

- Everyday 10 → 30（yes / no / excuse me / please / I love you / good morning / good night / I don't know / my Chinese is not good / cheers…）
- 新增 **Emergency** 分类 10–15 条（救命 / 报警 / 我迷路了 / 医院在哪 / 我过敏 / 帮我叫医生）
- Restaurant 补 3–4 条（有什么推荐 / 我吃素 / 我对花生过敏）

理由：唯一同时提升**搜索覆盖面**和**页面可用性**的动作。每条新增都会自动长出 1 个单句页 + 音频 + 词表。

**2. 收藏（♡ Save）**

新 storage key `rlc-saved-v1`，每张卡片一个 ♡，加 `/saved/` 页。

理由：现在的「Got it」语义是**我学会了**（进度），收藏的语义是**我待会要用**（工具）——旅行者要的是后者。零成本、零后端，而且它给了用户回访理由。

### P1（P0 之后）

**3. 错题复习。** Quiz 已有 best/attempts，扩 `wrongIds` → 学完给「Review these 2」，首页给「Continue where you left off」。把 quiz 从一次性玩具变成闭环的最小改动。

**4. 7 天旅行中文。** 不需要新内容，纯策展：把现有 + 新增短语切成 7 天，本地进度推进，首页给明确入口（“Going to China? 7 days”）。

**5. Privacy / Terms / Contact。** GA 已上线、受众以欧美为主 → 这三页现在是**合规缺口**，不是「以后有用」。成本极低。

**6. 单句页加实质内容。** When to use it / Similar phrases / 更自然的说法 → 把 100 词页做成 400–600 词页。这条是从「能被索引」到「能被排名」的关键。

### P2（先不做，等有数据）

7. 场景对话模拟器（#5）：产品价值高，但对 SEO 无贡献、开发量大。等收藏/复习有真实使用数据再做。
8. 意图索引版「what do you want to say」。
9. SEO 页广度扩张到 100+：先看 Search Console 前 30 天哪类词有 impression，再扩，别盲扩。

### P3（不做）

付费、AI 老师、会员、Dating。

## 6. 什么时候该重新考虑收费

三个条件**同时**满足再谈：

1. 短语 ≥ 300 条
2. 情景 ≥ 15 个
3. 自然搜索月访问 ≥ 2000

在那之前收费只会掐死增长。
